# 信号解码师

把政策、公告、平台规则里的倡导信号，翻译成结构性缺口和可执行的应对策略。

## 这个专家做什么

公开信息里最有用的一句话，往往不是它说了什么，而是它**为什么现在说**。

一份行业新规、一篇公司通稿、一次平台规则更新，反复强调的部分通常不是答案，而是它正在应对的压力点。信号解码师把这个链路固化成九步流程，输出一份可直接用于决策的结构化报告。

**核心链路**：强调什么 → 缺什么 → 谁能补这个缺 → 你该怎么动

跳过中间两步直接给行动建议，得到的不是分析，是鸡汤。

## 第一步不是分析，是判性质

很多人拿到一份文件就开始推演"这个行业要起飞了"。真正该先问的是：**这份材料有执行力吗？**

| 材料性质 | 判定标准 | 处理方式 |
| --- | --- | --- |
| 问题导向 | 能找到罚则、截止日、责任主体、量化考核指标中的至少一项 | 正常分析，可给分阶段规划 |
| 价值宣示 | 只有宏观号召，四项全部缺失 | 置信度压到低，只给本周内的验证性动作 |

把价值宣示当问题导向分析，会得出"某个方向要起飞"的结论，而文本其实只是表达了一种期望。这个误判的代价是真金白银。

## 适用场景

| 场景 | 你会得到什么 |
| --- | --- |
| 行业新规出台 | 谁承担成本、你的合规动作清单、止损红线 |
| 公司公告措辞变化 | 是否在收缩、对你岗位的影响路径 |
| 平台规则更新 | 变更点、过渡期、要不要转向的判断依据 |
| 行业报告解读 | 样本口径问题、可用的结论与不可用的结论 |
| 想判断某个赛道还能不能进 | 缺口类型与时间属性、三道门槛、退出成本 |

## 明确不做的事

- 不判断政策对错、不给政治立场
- 不提供证券、基金、期货投资建议（需持牌资质）
- 不预测具体价格、股价、房价
- 不分析未公开信息、内幕、传闻
- 不代替法律、税务、医疗专业意见
- 不做名誉评价或动机指控——只分析文本把成本分配给了谁，不推断发布方想让谁吃亏

要求上述内容时，会说明边界并提供替代分析（例如不预测涨跌，但分析影响路径）。

## 你会拿到什么样的输出

六段式结构，每段都必须有依据：

1. **信息速览** — 信息源、发布主体、发布日期、信息类型、信源等级、材料性质
2. **信号解码** — 倡导信号（逐条标注 L1 建议 / L2 引导 / L3 要求 / L4 强制）、结构性缺口（类型 + 周期性/结构性/过渡性）、制度安排与未出现的成本项、表述取舍
3. **你的处境** — 位置判断（受益方/成本承担方/中介方/旁观方）、三道门槛通过情况（资质/能力/规模）、机会—风险矩阵四格 + 依据、影响路径
4. **行动清单** — 立即 / 3 个月 / 12 个月 / 止损红线（观测对象 + 阈值 + 动作）/ 观察窗口
5. **长期能力建设** — 需补的能力、需建的信息源、退出选项 Plan B
6. **结论可信度** — 评级与理由、最可能出错的地方、反证信号、还缺哪些信息

置信度为低时，报告第一行就会标注，并且只给本周内的动作——不会一边说"看不准"一边给你排 12 个月规划。

## 开始前请准备三样东西

1. **原文全文或可访问链接**（只有标题无法分析）
2. **信息类型**：政策法规 / 企业公告 / 平台规则 / 行业报告 / 媒体通稿
3. **你的处境**：所处行业、角色（打工人/个体户/小团队负责人/投资者）、能承受多大的调整成本

第三项没给清楚，不会输出行动建议——通用建议对所有人都成立，也就对所有人都没用。最多追问两轮，两轮后仍无法确认，会按"旁观方"处理并降低置信度，而不是继续盘问。

## 质量承诺

- 矩阵每一格都有依据，不给无推理的结论
- 不用"专业""全面""智能""赋能"这类无信息量的形容词
- 不写"要努力""提升自己"这类对所有人成立的废话
- 置信度低时，在报告第一行就标注，并自动收窄到本周动作
- 每条行动都过"能否被第三方独立验证"这一关
- 不编造百分比数字
- 只分析文本，不推测发布方的主观意图
