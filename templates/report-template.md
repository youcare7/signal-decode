# 〔信息标题〕信号解码报告

**信源等级**：〔高 / 中 / 低〕　**置信度**：〔高 / 中 / 低〕

> 置信度为「低」时，本行必须置顶，且第四部分只输出「立即」档，第 2、3 小节留空。
> 材料性质为 declarative（价值宣示）时，置信度只能评 low；校验器会拦截 declarative 配 medium/high 的报告。

## 二、信号解码

### 1. 倡导信号

逐条列出，每条一行，标注强度。同一份材料内强度不同是常态，不要合并。

| # | 原文引用 | 规范性动词 | 强度 | 针对人群 |
| --- | --- | --- | --- | --- |
| 1 | 〔逐字引用〕 | 〔鼓励/应当/必须/严禁…〕 | 〔L1 建议 / L2 引导 / L3 要求 / L4 强制〕 | 〔具体是谁〕 |
| 2 | | | | |
| 3 | | | | |

**强度判定只看规范性动词，不看标题语气。**

### 2. 结构性缺口

- **缺口内容**：〔一句话，说明什么前提目前不成立〕
- **主类型**：〔供给不足 / 成本过高 / 信息不对称 / 信任缺失 / 能力不足 / 制度缺位〕
- **次要类型**：〔有则填，无则写「无」〕
- **时间属性**：〔周期性 / 结构性 / 过渡性〕
- **判定理由**：〔为什么是这个时间属性——这一项最容易亏钱，必须写清楚〕
- **成本承担方**：〔文本把成本分配给了谁，依据是哪句话〕

### 3. 制度安排与未出现的成本项

只描述文本如何组织，不推断发布方动机。

| 环节 | 内容 |
| --- | --- |
| 问题界定 | 〔它把什么情形界定为需要处理的问题〕 |
| 目标设定 | 〔承诺的终局状态〕 |
| 路径指定 | 〔要求通过什么方式达成〕 |
| 责任分配 | 〔要求谁行动、谁承担成本〕 |
| **未出现的成本项** | 〔哪一方的成本没被写进文本〕 |

### 4. 表述取舍

- **呈现了什么**：〔列举〕
- **省略了什么**：〔列举〕
- **文本语气**：〔紧迫 / 安抚 / 警示 / 中性〕
- **未被提及的替代解释**：〔至少一条〕

## 三、你的处境

### 1. 位置判断

- **角色**：〔受益方 / 成本承担方 / 中介方 / 旁观方〕
- **依据**：〔结合用户行业、角色、资源情况说明〕
- **退出成本**：〔高 / 中 / 低〕+ 具体说明

### 2. 三道门槛

| 门槛 | 是否通过 | 依据 |
| --- | --- | --- |
| 资质门槛 | 〔是 / 否〕 | 〔需要什么证照、许可、备案〕 |
| 能力门槛 | 〔是 / 否〕 | 〔需要什么技能、团队、经验〕 |
| 规模门槛 | 〔是 / 否〕 | 〔需要多少资金、产能、渠道〕 |

> 三道全过才是真机会。任何一道不过，机会只存在于「帮别人过门槛」这个位置。

### 3. 机会—风险矩阵

| 隐藏机会 | 〔一句话，含对象和动作〕 | 〔原文条款或推理链〕 | 〔需要什么才能吃到〕 |
| 显性风险 | 〔一句话〕 | 〔原文条款或推理链〕 | 〔触发条件〕 |
| 隐性风险 | 〔一句话〕 | 〔原文条款或推理链〕 | 〔触发条件〕 |

## 四、行动清单

每条行动的合格标准：**能否被第三方独立验证是否完成**。

反例：「提升核心竞争力」——无法验证。
正例：「连续 30 天发布记录中 AI 仅用于选题与提纲」——可验证。

### 1. 立即（本周内）

1. 〔动作〕— 何时：〔本周内〕— 可验证：〔做完能看到什么状态〕— 预算上限：〔金额，无则写 0〕
2. 〔动作〕— 同上
3. 〔动作〕— 同上

### 2. 3 个月内

置信度为「低」时本节留空。

1. 〔动作〕— 何时：〔3 个月内〕— 可验证：〔判据〕— 预算上限：〔金额〕— 放弃条件：〔什么情况就停〕
2. 〔动作〕— 同上

### 3. 12 个月内

置信度为「低」时本节留空。

1. 〔布局〕— 何时：〔12 个月内〕— 可验证：〔里程碑判据〕— 预算上限：〔金额〕— 放弃条件：〔什么情况就停〕

### 4. 止损红线

三要素缺一不可：观测对象 + 阈值 + 触发动作。

| 观测对象 | 阈值 | 触发动作 |
| --- | --- | --- |
| 〔指标或事件〕 | 〔具体数字或状态〕 | 〔停止 / 转向 / 加码〕 |
| | | |

### 5. 观察窗口

| 观察对象 | 关注指标 | 判断阈值 | 复查时点 |
| --- | --- | --- | --- |
| 〔事件或指标〕 | 〔具体数字或状态〕 | 〔超过/低于多少代表什么〕 | 〔YYYY-MM〕 |

1. **需要补的能力**：〔具体能力项，说明它对应上面哪个缺口〕

## 六、结论可信度

- **置信度评级**：〔高 / 中 / 低〕
- **理由**：〔信源质量 + 推理完整性 + 缺口归类的确定性〕
- **最可能出错的地方**：〔具体指出哪一步推理最脆弱，不要写"可能存在偏差"〕
- **反证信号**：〔出现什么就说明本判断失效〕
- **还缺哪些信息**：〔列出能提高确定性的关键信息，不要写"需要更多数据"〕
- **本报告不做的事**：不构成投资、法律、税务、医疗建议；不预测具体价格；不评价政策优劣；不推测发布方主观意图。
