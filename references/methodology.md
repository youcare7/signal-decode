# 方法论：从倡导信号到结构性缺口

本文是这个技能的理论核心。所有执行步骤、检查清单、模板都从这里推导出来。

---

## 一、核心命题

> 公开信息里最有用的一句话，往往不是它说了什么，而是它**为什么现在说**。

一条政策、一份公告、一次规则更新，反复强调的部分通常不是答案，而是它正在处理的压力点。

这句话可以拆成三个可操作的推论：

| 推论 | 含义 | 可验证性 |
| --- | --- | --- |
| **强调 ≠ 现实** | 反复倡导某事，说明现状尚未达到 | 可查：倡导频率、措辞强度、配套措施 |
| **倡导 = 成本转移** | 每次倡导都在指定"谁该承担什么" | 可查：谁被号召、谁被约束、谁被免责 |
| **缺口 = 机会** | 未被满足的需求是价值来源 | 可查：缺口类型决定机会类型 |

---

## 二、完整链路

```
强调什么  →  缺什么  →  谁能补这个缺  →  你该怎么动
   ↑            ↑              ↑                ↑
 第一步        第二步         第三步           第四步
 信号识别    缺口诊断       主体定位         行动设计
```

四步缺一不可。**跳过第二步直接给建议，就是鸡汤。**

### 前置：材料性质预判（为什么"有倡导"不一定"有缺口"）

核心命题"强调 ≠ 现实"有一个失效边界：纯公关性的价值宣示。这类文本是修辞需要，不安排责任主体、不设考核、不挂罚则，也就没有真实的成本转移——"倡导 = 成本转移"这条推论在它身上不成立，缺口自然也不存在。

| 材料性质 | 核心指标 | 处理规则 |
| --- | --- | --- |
| problem_oriented 问题导向 | 含明确截止日、责任主体、罚则、验收指标至少一项 | 三推论成立，进入正常分析，可评对应置信度 |
| declarative 价值宣示 | 只有宏观号召，罚则、考核、责任主体、时间点全缺 | 判定为形式倡导，置信度直接压到 low，阻断长期规划 |

这一步是整个链路的入口闸门：先确认材料"值得分析"，再谈缺口和行动。为不存在的市场需求制定方案，比不分析更危险。

---

## 三、第一步：识别倡导信号

### 3.1 什么算倡导信号

文本中出现以下任意特征，即为倡导信号：

- **规范性动词**：应当、必须、鼓励、支持、引导、严禁、不得、要求
- **价值判断词**：健康、理性、有序、高质量、可持续、负责任
- **行为号召**：呼吁、倡议、共同、自觉、主动
- **时间紧迫性**：加快、抓紧、尽快、限期

### 3.2 信号强度分级

| 级别 | 措辞特征 | 约束力 | 对个体的含义 |
| --- | --- | --- | --- |
| **L1 建议** | "鼓励""支持""倡导" | 无强制 | 可以做，也可以不做 |
| **L2 引导** | "应当""宜""原则上" | 弱约束 | 不做可能被约谈或通报 |
| **L3 要求** | "必须""应当""限期" | 强约束 | 不做即违规 |
| **L4 强制** | "严禁""不得""违者" | 法律效力 | 违反有明确罚则 |

**判定方法**：找原文的规范性动词，不要看标题。标题写"关于促进 X 健康发展的意见"，正文可能是 L2 引导；标题写"关于 X 的提示"，正文可能含 L4 禁止条款。

### 3.3 必须提取的元数据

| 字段 | 为什么重要 |
| --- | --- |
| 发布主体 | 决定权威等级与适用范围 |
| 发布日期 | 决定时效性，以及是否有配套文件 |
| 生效时间 | 决定你的准备窗口 |
| 文号 | 决定能否追溯原文（无文号多为解读稿） |
| 发布渠道 | 官网 / 转载 / 自媒体，决定信源等级 |

## 四、第二步：反向诊断结构性缺口

### 4.1 诊断方法

对每个倡导信号问三个问题：

1. **这个倡导成立的前提是什么？** 前提目前不成立吗？
2. **如果现实已符合倡导，还需要倡导吗？** —— 不需要。所以倡导本身证明了缺口存在。
3. **倡导的成本由谁承担？** —— 找文本里没提成本的那一方。

### 4.2 六类缺口与对应的机会形态

这是整个方法论最实用的部分：**缺口类型直接决定机会类型**。

| 缺口类型 | 判定信号 | 对应机会 | 典型形态 |
| --- | --- | --- | --- |
| **供给不足** | "加快培育""扩大供给""鼓励发展" | 进入市场 | 新产品、新服务、区域代理 |
| **成本过高** | "降低成本""减轻负担""优化流程" | 降本方案 | 工具、外包、流程改造 |
| **信息不对称** | "加强宣传""提高认知""普及" | 中介服务 | 咨询、培训、信息聚合 |
| **信任缺失** | "加强监管""规范秩序""建立信用" | 认证担保 | 合规服务、审计、背书 |
| **能力不足** | "提升能力""加强培训""人才短缺" | 培训代做 | 课程、代运营、驻场 |
| **制度缺位** | "建立健全""完善机制""填补空白" | 合规咨询 | 制度设计、标准制定 |

**使用方法**：先判缺口类型，再查机会形态，最后验证门槛。**不要反过来——先想好要做什么，再去找理由。**

### 4.3 缺口的时间属性

| 属性 | 判定 | 策略含义 |
| --- | --- | --- |
| **周期性** | 随经济周期或行业周期波动 | 等周期，不要重投入 |
| **结构性** | 由制度或技术条件决定，短期不会消失 | 可以重投入 |
| **过渡性** | 因政策切换产生的临时真空 | 快进快出，设明确退出点 |

**误判代价**：把过渡性缺口当结构性缺口，是最常见的亏钱方式。政策落地完成后，临时真空会被填上。

## 五、第三步：定位补缺主体

缺口存在不等于你能补。必须过三道门：

### 5.1 门槛清单

| 门槛 | 问题 | 不合格的表现 |
| --- | --- | --- |
| **资质门槛** | 补这个缺需要许可证吗？ | 需要但你没有 → 直接出局 |
| **能力门槛** | 你具备交付能力吗？ | 需要 3 年经验你只有 3 个月 |
| **规模门槛** | 最小可行规模是多少？ | 需要 50 人团队你只有 2 人 |

**三门槛全过才是真机会。** 过不了任何一道，这个缺口对你就不是机会——是别人的机会。

### 5.2 位置判断

用户在缺口链条中的位置，决定策略完全不同：

| 位置 | 特征 | 策略 |
| --- | --- | --- |
| **受益方** | 政策直接给资源或减负 | 顺势借力，尽快落地 |
| **成本承担方** | 被要求改造、被要求合规 | 低调避险，控制投入上限 |
| **中介方** | 连接供需两侧 | 边缘套利，做薄做快 |
| **旁观方** | 不受直接影响 | 长期筑基，或直接忽略 |

## 六、第四步：设计行动

### 6.1 风险-机会矩阵

四格必须全填，每格含三要素：**具体内容 + 判断依据 + 门槛**。

|  | 高确定性 | 低确定性 |
| --- | --- | --- |
| **高收益** | **A 直接机会**<br>已明确、可验证、门槛清晰 | **B 隐藏机会**<br>需推理，需验证假设 |
| **低收益** | **C 显性风险**<br>已知代价，可预算 | **D 隐性风险**<br>未显现，可能延迟爆发 |

**四象限策略**：

| 象限 | 策略 | 动作 |
| --- | --- | --- |
| A 顺势借力 | 快速投入 | 立即启动，设 3 个月验证点 |
| B 边缘套利 | 小成本试错 | 投入上限 = 可承受全损 |
| C 低调避险 | 控制暴露 | 合规优先，不做增量投入 |
| D 长期筑基 | 建立缓冲 | 能力储备 + 退出选项 |

### 6.2 行动清单颗粒度要求

**不合格**：
- "关注政策变化"
- "提升核心竞争力"
- "把握机遇，迎接挑战"

**合格**：
- "本周内查 X 平台规则第 3.2 条的过渡期截止日，若早于 12 月 31 日则启动方案 B"
- "3 个月内投入不超过 2 万元测试 Y 服务，若 30 天内无 5 个付费用户则停止"

**判定标准**：一条行动是否合格，看它能否被**第三方独立验证是否完成**。不能验证的就是废话。

### 6.3 止损红线

每条投入必须配一条可观测的止损信号：

| 要素 | 要求 | 示例 |
| --- | --- | --- |
| 观测对象 | 具体指标 | 付费用户数 |
| 阈值 | 明确数字 | 连续 30 天 < 5 |
| 动作 | 停止 / 转向 / 加码 | 立即停止投入 |

**没有止损线的行动不是决策，是赌博。**

## 七、置信度评级

### 7.1 三级评定

| 等级 | 条件 | 输出限制 |
| --- | --- | --- |
| **高** | 原文可查 + 缺口类型明确 + 门槛已验证 | 可给完整行动清单 |
| **中** | 原文可查，但缺口类型需推理，或门槛未验证 | 行动清单最多给到"3 个月"档 |
| **低** | 原文不可查（二手转述），或关键假设无法验证 | **报告第一行标注**，行动清单只给"立即"档 |

### 7.2 必须声明的不确定性

每份报告结尾必须回答：

1. 这份分析最可能错在哪里？
2. 出现什么信号说明判断错了？
3. 有哪些信息是我没有的？

## 八、七条铁律

违反任何一条，整份分析作废：

| # | 铁律 | 违反后果 |
| --- | --- | --- |
| 1 | **倡导当事实** | 把"应该发生"当成"将会发生" |
| 2 | **相关当因果** | 得出错误归因 |
| 3 | **过度外推** | 地方规定推全国趋势，单案例推行业 |
| 4 | **动机指控** | 从分析滑向揣测 |
| 5 | **幸存者偏差** | 只看成功案例，忽略沉默的大多数 |
| 6 | **时间尺度错配** | 把趋势当拐点，或把拐点当趋势 |
| 7 | **伪精确** | 编造百分比，制造确定感 |

## 九、与原始版本的差异

本方法论源自 [youcare7/news-analysis-prompt](https://github.com/youcare7/news-analysis-prompt)（CC0-1.0），保留的核心是"倡导信号 → 结构性缺口 → 个体行动"这条链路。

**剥离的部分**：

| 原版 | 本版 | 原因 |
| --- | --- | --- |
| 解构媒体叙事 | 分析公开文件 | 叙事解构涉及时政立场 |
| 评价政策对错 | 只分析影响路径 | 价值判断超出分析边界 |
| "宏大叙事"框架 | "制度安排"框架 | 术语中立化 |
| 个体 vs 系统对抗 | 个体在约束下优化 | 立场中性化 |

**新增的部分**：缺口六类型映射、三门槛检验、止损红线、置信度门控、机器可校验的输出 schema。

---

## 十、边界

本方法论**不适用于**：

- 需要持牌资质的判断（投资、法律、医疗、税务）
- 未公开信息、内幕、传闻
- 对政策的价值评判
- 具体价格预测

遇到上述需求，说明边界并提供替代分析（例如"不预测涨跌，但可以分析影响路径"）。
